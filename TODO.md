## Двуязычная оболочка и навигация

- [x] Приложение предоставляет полностью двуязычный интерфейс на русском и английском языках с переключением RU / EN в один клик.

## Главная страница и визуальная система

- [x] Интерфейс использует Next.js App Router, TypeScript, Tailwind CSS, Lucide React и mobile-first адаптивную вёрстку.
- [x] Визуальный стиль минималистичный и чистый, с крупной типографикой, удобными для телефона кнопками и визуальным направлением в духе Laowai Drive.
- [x] Главная страница показывает понятное позиционирование приложения, выбор экзамена, карточки режимов, счётчик вопросов и сохранённый прогресс.

## Практика

- [x] Режим Practice показывает один вопрос за раз.
- [x] В Practice после выбора ответа мгновенно отображается цветовая индикация правильного или неправильного ответа.
- [x] После ответа в Practice отображается объяснение; для multiple-choice проверяется полный набор выбранных вариантов.
- [x] QuestionCard поддерживает true/false, single-choice и multiple-choice, состояния выбора, обратную связь и адаптивное отображение изображения вопроса.

## Пробный экзамен

- [x] Mock Exam запускается со 100 случайными вопросами без повторов, таймером 45 минут и проходным баллом 90/100.
- [x] Во время Mock Exam приложение показывает прогресс сверху и не раскрывает правильность отдельных ответов до завершения.
- [x] ExamTimer использует обратный отсчёт и автоматически завершает экзамен после истечения 45 минут.
- [x] Результаты Mock Exam показываются только в конце и содержат итоговый балл, процент, статус сдачи и возможность повторного запуска.

## Ошибки и локальное сохранение

- [x] Неверно отвеченные вопросы автоматически добавляются в MistakeTracker.
- [x] Список ошибок, язык и текущая сессия сохраняются в localStorage и восстанавливаются после перезагрузки.
- [x] Раздел Mistakes показывает количество ошибок и позволяет повторно пройти вопросы.

- [x] Данные вопросов загружаются из локальных JSON-файлов с единым контрактом `id`, `subject`, `type`, `question_ru`, `question_en`, `options_ru`, `options_en`, `correct_index`, `correct_indices`, `explanation_ru`, `explanation_en`, `image_url`; `data/questions.json` содержит полный импорт.
- [x] Полный банк содержит 4 378 вопросов: 2 545 Subject 1 и 1 833 Subject 4; поддержаны true/false, single-choice и multiple-choice.

## Freemium и продолжение обучения

## Мобильное веб-приложение

- [x] DrivePrep можно установить на телефон как PWA: manifest, standalone-режим, theme color и иконки 192/512 px.
