# DrivePrep

Бесплатное двуязычное приложение для подготовки к теоретическим экзаменам на водительские права в Китае — Subject 1 и Subject 4. Интерфейс доступен на русском и английском языках.

## Что внутри

- Полный локальный банк из 4 378 вопросов: 2 545 для Subject 1 и 1 833 для Subject 4.
- Практика по всему банку с мгновенной проверкой, объяснением и режимами true/false, single-choice и multiple-choice.
- Mock Exam на 100 случайных вопросов, 45 минут и проходной балл 90/100.
- Раздел работы над ошибками, локальный прогресс и PWA-оболочка.
- Никаких платных режимов, кодов доступа, пользователей, внешнего API, Cloudflare Worker или базы данных.
- Источник проекта и полный банк находятся в GitHub-репозитории: https://github.com/Xoppop888/Driver_Test.
- На главной странице размещены двуязычный блок поддержки проекта и рекламный блок Binhai Auto: https://binhaiauto.ru.

## Локальный запуск

Требуется Node.js 20+ и pnpm 10+.

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`. Проверки и production build:

```bash
pnpm typecheck
pnpm build
```

После `pnpm build` статический результат находится в `out/`.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` собирает статический экспорт и публикует `out/` через GitHub Pages. Backend secrets и API variables не нужны.

1. Загрузите проект в ветку `main`.
2. В настройках репозитория включите **Settings → Pages → Source: GitHub Actions**.
3. Сделайте push в `main` или запустите workflow вручную.
4. Для project Pages приложение автоматически использует `basePath` вида `/<repository>`.

GitHub остаётся единственным источником кода и банка вопросов. При обновлении базы изменяйте `data/questions.json`, проверяйте `pnpm typecheck && pnpm build` и отправляйте commit в репозиторий.

## PWA и мобильные устройства

Откройте опубликованный сайт по HTTPS в Chrome или Edge и выберите **Установить приложение** или **Добавить на главный экран**. На iPhone используйте Safari: **Поделиться → На экран «Домой»**.

Язык, прогресс, ошибки и последняя позиция практики сохраняются локально в браузере. Внешняя база данных и аккаунты не используются. Вёрстка учитывает safe-area мобильных устройств и не допускает выхода длинных вариантов ответа за пределы экрана.

## Обновление банка вопросов

Основной файл — `data/questions.json`. Вспомогательные скрипты для подготовки данных находятся в `scripts/`:

```bash
python3 scripts/download_question_images.py --help
python3 scripts/batch_translate_questions.py --help
python3 scripts/finalize_bank.py --help
```

Банк и изображения происходят из архива 2022 года. RU/EN-тексты машинно переведены для учебного использования. Перед публичным или коммерческим распространением проверьте права на изображения и актуальность правил. Подробности находятся в [`data/ATTRIBUTIONS.md`](data/ATTRIBUTIONS.md).

## Реклама и поддержка

Рекламный блок на главной ведёт на `https://binhaiauto.ru` и помечен как реклама. Блок поддержки ведёт на GitHub-репозиторий проекта, где можно поставить звезду, открыть issue или предложить улучшение.

## CI/CD

- `.github/workflows/ci.yml` запускает TypeScript-проверку и production build на push и pull request.
- `.github/workflows/deploy-pages.yml` публикует статический экспорт в GitHub Pages.

Не добавляйте в репозиторий пароли, `.env` и приватные пользовательские данные.
