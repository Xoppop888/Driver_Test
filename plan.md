# DrivePrep — current plan

## Product direction

DrivePrep is a free, GitHub-first bilingual study app for China's driving theory exams. There are no paid modes, access codes, accounts, external database, Cloudflare Worker or premium API. The full local question bank remains in `data/questions.json`.

## Design direction

Keep the existing editorial roadbook visual language: warm paper background, ink panels, coral accent, generous typography, compact rounded controls and clear mobile safe-area spacing. Use Russian and English equally throughout the interface.

## Current deliverable

The home page presents Practice, the 100-question Mock Exam, subject selection, a GitHub support block and a clearly labelled sponsored Binhai Auto block linking to `https://binhaiauto.ru`. GitHub Pages remains the deployment target and GitHub remains the source of truth.
